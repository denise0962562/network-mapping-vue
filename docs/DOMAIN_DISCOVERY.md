# 域名发现与证书关联

菜单“域名发现”对应 `/domain-discovery`。输入种子域发起后台发现，可补充完整 SAN 与跨域证书关联；域名链接进入 `/domains/:domain` 查看已保存证据，查看不会自动继续发现。

历史默认展示当前用户最近 100 个作业。来源作业链接及复用结果按作业 ID 读取，即使不在这 100 项中也能打开；未完成的作业持续按 ID 查询状态。结果支持名称及关系筛选、每页 100 项，并展示证据完整性、证书有效期、指纹和 crt.sh 链接。查询匹配名称与完整 SAN 分别标记；通配证书不展开为具体主机，同证书不代表同组织。

可选择最多 500 个具体名称提交 DNS 验证；排除项、通配模式和该作业已提交项不能重复选择。后端重新校验结果来源和当前排除策略；并发或重复请求复用已有 DNS 提交。DNS 解析结果在任务详情查看，发现列表不把“任务已提交”误标为“已解析”。

需先部署包含 domain_discovery 作业表与证据 API 的后端，再部署前端。ES 和 crt.sh 出站访问条件、配额和备份说明见服务端 `docs/DOMAIN_DISCOVERY.md`。强制刷新受配额和冷却限制；外部源失败和结果截断均会显示，已有证据仍可查看。

验证：`node --test src/utils/domainDiscovery.test.js src/views/DomainDiscovery.test.js`、`pnpm build`。交互验收覆盖创建/复用、取消、历史窗口外的来源作业、部分结果、域名关联跳转、排除策略变化、选择上限和重复 DNS 提交。
