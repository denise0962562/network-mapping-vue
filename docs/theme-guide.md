# 外观主题

主应用、登录、搜索和资产详情均提供 daisyUI `swap-rotate` 三态主题开关，使用 Lucide 的 Sun（亮色）、Moon（暗色）和 SunMoon（跟随系统）图标，点击或按空格键依次循环切换。图标之间使用 300ms 旋转和淡入淡出过渡；开启减少动态效果的系统偏好时关闭过渡动画。首次访问默认跟随系统；手动选择亮色或暗色后，系统设置变化不会覆盖用户选择。

偏好保存在当前站点的浏览器 `localStorage` 中，键为 `network_mapping_theme`。同源标签页通过 `storage` 事件同步。清除或删除偏好后恢复跟随系统；存储不可用时仍可在当前页面切换。外观属于浏览器偏好，不写入服务器的系统设置。

## 初始化与复用

- `public/assets/theme-init.js`：四个 HTML 入口在 `<head>` 中同步加载，在应用挂载前设置根元素的 `data-theme` 和 `color-scheme`，避免刷新暗色页面时先显示亮色。脚本通过现有 `/assets/` 静态资源路径分发。
- `src/composables/useTheme.js`：为 Vue 提供只读的用户偏好、实际主题、暗色状态及设置方法。
- `src/components/ThemeToggle.vue`：四个入口共用的三态图标开关，使用 checkbox 的 `checked` / `indeterminate` 状态显示对应模式，具有可访问名称并支持键盘操作。
- `src/composables/useChartTheme.js`：在原有图表配置上补充实际主题、文字、网格、图例和 Tooltip 颜色，保留数据、事件及交互配置。通过响应式 options 更新现有图表。

新增独立 HTML 入口时也应同步加载主题脚本。新增图表应使用 `useChartTheme(() => ({ ... }))`，图表数据与业务配置保持在所属组件中。

## 配色约定

页面背景、卡片、边框和文字优先使用 daisyUI 的 `base-200`、`base-100`、`base-300` 和 `base-content`。成功、错误、警告及信息状态使用对应语义颜色。不要把 `text-neutral` 当作正文颜色，也不要用固定黑色填充可随主题变化的 SVG 图标；图标应使用 `currentColor`。

图表 Tooltip、菜单及地图控件的外壳颜色集中在 `src/style.css`。维护标注使用主题变量。邮件编辑器动态更新 CodeMirror 主题和高亮扩展，保留编辑内容及撤销历史。

二维码保留白底黑码。邮件 HTML 预览展示邮件自身的配色。报告打印采用白底深色文字，并隐藏导航与操作控件。

## 验证

运行 `pnpm test:theme` 检查偏好恢复、系统变化、跨页面同步、存储受限及图表配置保留；运行 `pnpm build` 验证四个入口的生产构建。

浏览器验收应覆盖四个入口的三种偏好、刷新首屏、跨标签页同步、手机视口，以及加载、空数据、失败、弹窗、禁用和焦点状态。切换时检查图表缩放和编辑器未保存内容、选区及撤销历史；检查二维码、邮件预览和报告打印的独立配色规则。
