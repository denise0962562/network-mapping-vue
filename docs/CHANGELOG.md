### 新增与调整

- **中英文界面**：控制台、登录、独立搜索和资产页按浏览器首选语言初始化；手动选择保存一年期 cookie，保留业务草稿与状态。统计标题和说明响应语言变化，保留自定义标题；固定明细 CSV 契约不随界面语言改变。见[语言规则](LOCALIZATION.md)。
- **自动服务与 UDP**：TCP 默认识别全部已实现协议，移除协议复选框；UDP 主动/被动各用其支持的默认协议集。TLS/SNI/公开 CA、DoH 路径、Modbus Unit ID、S7 TSAP、MQTT 版本放入 daisyUI 折叠高级参数，预览和创建参数一致。
- **协议证据与端点**：统一服务徽标和历史证据，展示 DNS/RFB、工业、MQTT 合法认证拒绝和被动来源；列表键及资产历史区分同端口 TCP/UDP。动态证据按文本转义，被动观察不显示为端口开放。节点筛选核对协议能力和单端点预算。
- **系统与 Web 识别**：搜索、任务及资产详情展示操作系统线索、Web 技术及本地图标，兼容版本冲突、不完整/过期状态；增加 database/Elasticsearch REST 标签，任务结束后继续轮询未完成的派生识别。见[Web 识别](WEB_DETECTION.md)。
- **统一通知**：同页管理邮件、飞书、Telegram 渠道、订阅、测试和投递历史，支持独立代理；按渠道编辑模板、变量、草稿和历史，自动预览并测试未保存模板。见[通知渠道](NOTIFICATIONS.md)。
- **登录与域名发现**：可选 Turnstile 登录和管理员设置，普通用户不显示管理入口；提供共享 DNS 排除策略、证书候选/同证书关系、后台发现作业与显式 DNS 验证。见[登录验证](HUMAN_VERIFICATION.md)、[域名发现](DOMAIN_DISCOVERY.md)。
- **可信情报**：来源和加密数据库凭据管理、离线上传/进度/断点恢复、ASN 与手工文章；文章 IOC 提议显示原文高亮、失败阶段和诊断，接纳/纠正/拒绝操作保留人工审核。见[威胁情报](THREAT_INTELLIGENCE.md)。
- **LLM 管理与调试**：新增基础/供应商导航、单一 IOC 供应商与模型绑定、模型发现与手工维护、Chat/Responses、全局/局部代理与请求头/session/流式设置；支持多轮调试、参数侧栏、提示词编辑、思考/用量/速度/缓存命中。对话留存默认关闭，启用后可加载/删除/重放历史；未发送输入按用户在浏览器保留七天。见 [LLM 使用](LLM.md)。
- **双语文档**：新增 MkDocs 中英文入口和部署页，默认构建、预览与部署完整生成 `en/` 页面、资源和索引；缺译专题明确链接中文原文，不自动翻译采集证据、历史文本或已保存模板。

- 修复统计“其他”聚合行下钻，真实同名类别仍可打开明细；语言切换保留统计语义、CSV 固定列名/值与时间格式。

- 补充转义证据的大小写/事件载荷回归，保留 CodeQL 检查；CI 覆盖全部工具、视图、组件与语言测试。更新 axios、DOMPurify **3.4.17**、Vite **7.3.7**、Browserslist、follow-redirects、pnpm 和 Actions，新增 Vue I18n **11.2.8**。

### 升级与兼容

1. 配套服务端 **0.1.30**、Scanner **0.1.21**；后端先完成[传输端点迁移](https://github.com/wshijiang/network-mapping/blob/main/docs/SERVICE_PROTOCOLS.md#存储升级与回滚)，模块使用完整 IPC **3** 套件，再启用 UDP/工业协议功能。

3. 先部署新版登录页再启用 Turnstile；LLM/通知/情报界面需配套 API。界面语言不改变权限、扫描目标、协议枚举、业务时区、历史证据或已保存通知模板。
