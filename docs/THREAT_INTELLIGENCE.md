# 威胁情报管理与自动标记

[功能指南](FEATURES.md) · [维护指南](maintenance-guide.md)

管理员从“设置 → 威胁情报”进入 `/admin/intel`。默认可信官方结构化 IOC 直接接纳，
不使用来源置信度或多来源数量作为通过条件。管理员可对每个来源启用人工审核。
RSS 文章的 AI 提取结果始终人工审核，无法关闭这一规则。
手动提交文章也遵循同一固定审核规则。

## ASN、攻击行为与手动文章

IOC 库支持 ASN（例如 `AS64496`），可以按 IOC 类型与攻击行为筛选。行为分类包括 BGP
路由劫持、路由泄漏、DNS 劫持、DNS 应答篡改、恶意重定向、钓鱼、恶意软件投递、命令
与控制、凭据窃取、数据外传、拒绝服务及侦察。证据与审核详情显示行为、指标角色和资源
登记方；登记方不会自动成为攻击者或 MITRE 组织。行为分类与原文明示的 ATT&CK 编号分开。

搜索结果和资产概要展示独立的“所属 ASN：恶意报告 / 可疑报告 / 已过期”徽标。该证据
针对资产已记录的 ASN，不改变 IP 自身风险，不生成派生 IP IOC，也不证明流量路径经过
该 AS。ASN 和 IP 均被报告明确列名时，两个证据范围分别展示。ASN 沿用来源审核、撤销
及默认六个月到期规则。

接入微信公众号或单篇报告：

1. 在来源页新建“手动文章 / 微信正文”，配置允许的完整域名，例如 mp.weixin.qq.com。
   此类型只接受手动提交，来源地址和凭据留空，没有周期抓取。
2. 需要远程抓取微信正文时，在来源填写具体账号 `__biz`，不能填昵称。后端核对页面
   发布账号，读取正文及表格，不执行脚本；仅域名匹配不能证明属于官方账号。
3. 在文章页展开“提交文章链接 / 正文快照”，选择来源、填写标题和 HTTPS 原文地址。
   留空正文将由后台抓取；验证页、网络受限或账号不明时可粘贴 40～100,000 UTF-8 字节
   的纯文本。手动正文标明“管理员提供，尚未核验网络发布账号”，不会变成可信结构化数据。
4. AI 关闭时文章保存并等待；开启后生成提议。审核时核对 ASN、IP、行为、指标角色及
   原文快照，人工接纳后生效。原文未明确每个地址的 DNS 角色时，不批量推断为恶意 DNS。

微信链接的 poc_token 等访问/跟踪参数不保存，仅保留文章身份参数。重复提交相同内容
幂等，新正文形成独立快照，重试复用原快照。修改/停用来源会取消旧版本任务。
正文抓取使用公开页面，不绕过验证；系统当前也不采集 BGP 路由流或主动监测 DNS 劫持。

## 管理流程

1. 在“来源”确认或添加数据源，周期来源选择远程 HTTPS 或本地文件；历史导出选择离线上传。
   ThreatFox 持续更新使用 API，导出文件仅用于手动补齐历史。
2. 在“MITRE 基准库”查看同步的组织、软件和技术；关联名称只用于候选，不能直接当作
   等价别名。未收录组织不自动创建。
3. 在“IOC 库”查看直接接纳的可信 IOC，按状态或 IOC/软件/组织原名搜索。
4. AI 可独立开关。开启前填写兼容接口、模型，并保存数据库加密凭据或填写密钥环境变量
   名称；关闭后，可信 IOC
   同步及已有标记继续运行。
5. 在“文章”查看发现和提取状态；AI 开启时可重试失败记录或重新提取已完成文章，复用
   保存的正文快照，新提议仍须审核。
6. 在“审核”并排核对 IOC 提议、具体证据和原文快照，填写说明后接纳或拒绝。
7. 在“名称映射”核实来源组织/软件名称对应的 MITRE G/S 编号，也可撤销映射。基准库
   支持查看对象与关系，软件使用关系不会自动产生当前 IOC 的组织归因。
8. 在“同步作业”查看成功、分批继续、缺少凭据或上游失败；需要纠错时在 IOC 库撤销
   对应证据，其他来源证据不会被删除。

来源周期范围 60～2,592,000 秒，默认 MITRE 86,400、GitHub 3,600、RSS/ThreatFox/通用
JSON 和文本 1,800 秒。ThreatFox 离线导入没有定时文件抓取。本地路径相对于服务端
`NM_INTEL_LOCAL_ROOT`，不能填写任意服务器路径。

来源与 AI 均提供“数据库加密凭据”密码框，复用服务端已有 AES-256-GCM 实现。留空保留
已存值，填写新值替换，勾选“清除”才删除；读取接口不返回明文或密文。数据库凭据优先，
未保存时使用环境变量备用来源。ThreatFox 填原始 Auth-Key，其他来源填完整 Authorization
值，AI 填原始 API Key。环境变量输入框只填 `NM_INTEL_*` 名称。切换本地或离线上传会清除该
来源的数据库凭据。解密失败时不会自动回退，应先检查服务端主密钥。

修改来源时必须保留服务端返回的 revision，过期版本返回冲突。轮询不会覆盖未保存的
来源或 AI 设置草稿。审核绑定记录的内容哈希，不能用旧页面批准新提议。

AI 提议必须成功加载非空原文快照才能接纳；加载失败时显示独立错误与重试入口，不能
把缺失正文当作结构化来源。重试保留已填写说明。证据不足时仍可拒绝提议或撤销已接纳
证据。修改来源后，旧版本待提取文章会取消且不能重试；重新同步会按新来源版本发现
文章并建立独立快照，保留旧文章和历史证据。

## 离线导入与过期

在官方平台下载 JSON、CSV 或单文件 ZIP 后，选择“ThreatFox 离线历史导入 → 上传离线
文件”。系统只接收本地文件，不定时下载官方导出；增量更新仍由独立 ThreatFox API 来源
运行。支持官方完整/近期导出与 URL、域名、IP:端口、MD5、SHA256 子集，不需要给上传
来源配置上游凭据。通用 JSON/CSV 可以新建离线上传来源。
CSV 支持 UTF-8 BOM、CRLF、注释表头、逗号后的空格、带逗号/换行的引号字段和双引号
转义。`None` 等空参考值按缺省处理；数据行列数不匹配、未闭合引号和错误编码会拒绝导入。

上传最多 512 MiB，解压内容和规范化结果分别最多 2 GiB、单条最多 1 MiB、最多 1,000 万条。
文件先完整读取、校验，然后每批最多 1,000 条入库，页面显示阶段、有效总量和处理数量。
ThreatFox 原生记录中无法规范化的 IOC 单独隔离；来源与作业页可展开“已隔离”查看前
100 条异常的来源 ID、类型、原值和原因。有效记录继续按来源策略处理；异常记录不生成
标记，也不进入 AI 审核队列。包含隔离记录的离线原文件保留在服务端缓存中直到被新上传
替换；没有异常时校验完成清理原文件。文档损坏、超限或缓存错误仍拒绝整个文件，通用
JSON/CSV 保持严格校验，不提前发布有效前缀。重启后可继续，重复上传不会重复新增同版本证据；作业运行期间不能
覆盖文件。缓存丢失时重新上传原文件。服务器文件可选离线类型和本地路径后手动同步。
结构化导入采用批量事务，批次完成后立即继续；无需浏览器上传时可使用服务端
`intel import --fast`，默认每批 5,000 条；`--batch-size` 可设为 1～50,000，
`--max-batches` 控制本次提交批数，达到后持久暂停。使用 `--resume` 或 Web“继续导入”
恢复；详见
[CLI 快速导入](https://github.com/wshijiang/network-mapping/blob/main/docs/THREAT_INTELLIGENCE.md#cli-快速导入)。

开始上传前先检查服务端缓存和来源状态，最多等待 15 秒。检查会创建、写入、落盘并删除
私有探测文件，检查失败不发送大文件，也不创建导入作业。权限、来源版本和作业状态在
实际上传时会再次校验，检查通过不表示预留了导入名额。

没有进度事件时显示“正在连接服务器”的动画，收到字节事件后按浏览器总量或所选文件
大小计算进度；100% 后显示等待服务器保存和入队。错误直接显示在上传弹窗内，保留文件
供重试，支持取消等待。上传请求最多 30 分钟，离开页面会中止。代理的 413 通常表示上传
大小限制；请核对代理 import 路由是否允许 512 MiB、缓存权限及磁盘空间。已有同源作业
时会在接收文件前拒绝新上传，避免传完后才发现冲突。
CSV、JSON 结构、URL IOC 和参考链接错误会分别显示格式说明。URL IOC 支持 FTP/SMB、
TFTP/TCP、WebSocket（WS/WSS）
和无协议的主机/路径等官方报告形式，无协议值保持原样，不自动扩大为域名/IP 标记。
ESET 仓库个别 JSON 本身有语法错误时会隔离该文件，其他文件继续同步；作业汇总中的
`unsupported_files` 和 `unsupported_paths` 可查看跳过数量与路径，上游修正后自动重读。
ESET 原生 MISP 合格属性内的 IOC 格式错误会单独计入隔离报告，并显示文件路径；受害
目标、背景属性及已删除属性仍不作为恶意目标。升级后的解析器会重读旧版本文件一次。

已核对 [ThreatFox API 文档](https://threatfox.abuse.ch/api/)与完整导出：ioc_type 为指标
格式，threat_type 为用途分类。支持原生 md5_hash、sha1_hash、sha256_hash、domain、url、
ip:port；JSON/CSV 的字段别名、数字置信度、布尔值、UTC 时间和空参考值共用转换。
tags 在 API 示例中是数组，在本次导出中是字符串，均保留原始元数据。域名支持 IDN
和下划线，端口 0 保留为精确 IOC；不会把异常域名、软件家族或受害目标转换成恶意 IP。
官方六个月以前的 IOC 可能已从 API/导出移除，full 文件不保证包含永久全历史。

出现“服务端导入缓存不可用”时，需要处理后端进程的目录配置。默认路径为
`/var/lib/network-mapping/intel-cache`，普通账户通常无权创建；在后端启动环境设置
`NM_INTEL_CACHE_ROOT` 为服务账户可读写的持久目录并重启后端。这个变量使用单下划线，
仅在前端 `.env` 或 `pnpm dev` 终端设置无效；后端不自动读取前端环境。Docker 目录还须
在可写持久卷内，官方镜像账户为 UID/GID `10001:10001`，旧卷或 bind mount 的权限须
另行检查。后端日志提供实际路径和系统错误，完整操作见
[导入缓存权限排查](https://github.com/wshijiang/network-mapping/blob/main/docs/THREAT_INTELLIGENCE.md#导入缓存权限排查)。

同步的 `intel_dns_failed` 指服务进程或容器无法解析来源域名，应检查 DNS、代理与
NO_PROXY；`intel_proxy_dns_failed` 指代理域名无法解析。代理远程解析的连接不要求本机
先解析来源；直连仍校验目标地址。切换来源格式时，会自动纠正不支持的离线上传方式。

来源“自动情报有效期（月）”默认 6，可调 0～120。按最后观察、首次观察、首次入库时间
依次取基准，重复抓取同版本不会续期。0 不添加本地期限，来源明确到期仍生效。
超过期限的历史 IOC 保存为“已过期”，在 IOC 库选择该状态可追溯或撤销；不贡献当前风险。
其他来源仍有效时保留对应风险，人工标签不受影响。调整期限在后续查询立即反映。

## 标记展示

搜索结果显示端点情报，资产详情分别显示 IP 情报和端点情报；域名关联页查询精确域名。
点击恶意/可疑徽标查看来源、接纳方式、报告归因、家族、观察时间及证据。
只有过期证据时显示灰色“已过期”；证据弹窗区分有效与过期时间。

IP:端口命中不会扩大成整 IP，域名不会扩大成父域、子域或当前解析 IP，共享软件不会
自动增加组织归因。IOC 库中的 URL/哈希可以查询，但缺少真实 URL/样本观察时不显示
端点命中。没有情报不代表正常；服务不可用时显示“情报暂不可用”。

自动情报与人工标签分别展示，自动情报不覆盖人工标签。只有管理员可管理来源、文章
和审核；现有资产权限由后端继续执行。

## 开发与验证

新增 `ThreatIntelligence.vue`、`IntelEvidence.vue`、`IntelLookup.vue`、`IntelValidation.vue` 与
`utils/threatIntel.js`，接口前缀 `/api/intel`，复用现有 http 模块的会话及 CSRF 处理。
模型输出和正文用 Vue 文本插值显示，链接仅允许无凭据的 HTTPS 来源。

```sh
node --test src/utils/threatIntel.test.js src/views/ThreatIntelligence.test.js src/components/Intel*.test.js
pnpm build
```

服务端格式、API、数据库迁移和部署配置参见
