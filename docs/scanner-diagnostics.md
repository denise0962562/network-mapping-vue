# 扫描器详情：错误与日志

扫描器详情页 `/scanner/{id}` 在延迟历史之后显示“错误与日志”面板。它复用项目的 HTTP/CSRF、时间格式、Tailwind CSS 和 daisyUI，不需要增加前端配置。

## 管理员使用

1. “刷新目录”向服务端创建 list_logs 任务，下一次扫描器心跳通知后台处理；刷新当前页面数据不会直接读取扫描端目录。
2. 目录返回后选择最多 16 份日志，点击“采集选中的日志”。有效待处理任务存在时按钮禁用，避免重复创建；任务状态每 5 秒刷新。
3. 等待“已完成”，在“已采集日志”点击“下载”。下载的是请求处理时的完整行快照，原文件后来追加的内容不包含在内；尾部未完成字节数会显示。
4. 查看错误记录，按 ERROR/WARN 或错误码精确筛选，每页 50 条。展开可看操作、引擎、阶段、退出码等诊断数据，关联任务以及证据文件行号。
5. 证据文件属于最近返回的 50 份且已可下载时，可直接“下载证据日志”。“确认告警”记录人工知悉；通信或启动检查恢复由扫描端恢复事件判定。

页面显示最近 5 个告警和最近 5 个采集任务；服务端接口分别返回最多 50 条。它不提供完整告警历史分页或在线全文日志浏览。时间使用系统已配置时区和格式；源日志文件名按 UTC 天生成，二者日期不同属于正常现象。

## 状态说明

| 状态 | 展现 |
| --- | --- |
| 离线 | 显示已保存诊断，新请求等待重新连接，创建后 30 分钟过期 |
| 启动检查失败 | 停止领取任务提示，仍允许刷新目录和采集日志；修复后重启扫描端 |
| 诊断事件有丢弃 | 显示本次运行累计丢弃数，建议采集原始日志补充排查 |
| 旧扫描端 | 提示升级并等待首次心跳；已保存文件可下载 |
| 非管理员 | 显示权限提示，停止诊断轮询 |
| 服务不可用 | 保留已加载数据并提示重试；管理员可手动刷新 |
| 没有错误/文件 | 各自显示空状态，不推断扫描器一定健康 |
| 解析失败 | 已校验的原始日志仍可下载 |
| 文件过期/下载权限变化 | 显示下载失败提示，服务端重新验证权限 |

所有诊断查询和原始日志下载由服务端限制管理员 role=1；创建任务、确认告警携带既有 CSRF Token。页面不包含机器运行 Token。下载使用带会话的 HTTP blob，再生成临时对象 URL；渲染日志说明使用文本插值，不渲染日志中的 HTML。

服务端对应配置、协议、权限审计和升级步骤详见配套仓库 `docs/SCANNER_DIAGNOSTICS.md`，扫描端固定目录与持久化文件见 `docs/DIAGNOSTICS.md`。推荐先服务端、再扫描端、最后前端；本页需要新增诊断 API，连接未升级服务端时会提示加载失败。

## 实现与验证

- `src/components/ScannerDiagnostics.vue`：轮询、错误筛选/分页、任务创建、告警确认、文件下载。
- `src/views/ScannerDetail.vue`：面板接入，扫描器基本状态由既有详情刷新同步。
- 路由切换或销毁时取消当前查询并停止轮询；手动查询可替换未完成的轮询，避免旧结果覆盖新筛选。

```sh
pnpm build
pnpm dev
```

检查桌面与手机宽度、目录选择与采集参数、下载、告警确认、展开证据/关联任务、离线、启动失败、旧能力、空状态、服务错误与 403。前端仓库仍没有自动测试运行器；构建和本地浏览器模拟验证不能代替真实扫描端长期运行验证。
